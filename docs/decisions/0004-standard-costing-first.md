# 0004 — ตีราคาต้นทุนด้วย standard cost ก่อน ยังไม่ทำ FIFO

- สถานะ: ตกลงใช้
- วันที่: 2026-09-07
- เกี่ยวข้องกับ: เฟส 3, เฟส 5

## บริบท

เฟส 3 ระบุว่าต้องตัดสินใจวิธีตีราคาตั้งแต่ตอนนั้น เพราะมันกำหนดว่าตาราง
`stock_transactions` ต้องเก็บอะไรเพิ่ม ถ้าเลือก FIFO แล้วมาเพิ่มทีหลังจะแพงมาก

## ทางเลือกที่พิจารณา

**Standard cost (เลือก)**
`unit_cost` ของทุกธุรกรรมมาจาก `items.standard_cost` ณ เวลาที่ลงธุรกรรม
และถูกตรึงไว้ในแถวนั้นตลอดไป ต้นทุนจริงของใบสั่งผลิต = ผลรวมของ
`total_cost` ในธุรกรรมที่เบิกจริง หักที่คืน

ข้อดี: กางเป็นรายบรรทัดได้ตรงไปตรงมา ไม่มีสถานะซ่อนอยู่ที่ไหน
และเหมาะกับโรงงานที่ราคาวัตถุดิบไม่ผันผวนรายวัน

**FIFO — ตัดทิ้งในรอบนี้ แต่เผื่อทางไว้แล้ว**
ให้ต้นทุนแม่นกว่าเมื่อราคาผันผวน แต่ต้องมีตาราง layer และการอ้างถึง layer
ที่ถูกตัดในทุกธุรกรรมขาออก ซึ่งเพิ่มความซับซ้อนของ `post_transaction`
อย่างมีนัยสำคัญตั้งแต่วันแรก

ทางที่เผื่อไว้: `stock_transactions` เก็บ `unit_cost` และ `total_cost`
รายแถวอยู่แล้ว การเพิ่ม FIFO ภายหลังจึงเป็นการเพิ่มตาราง layer กับคอลัมน์
อ้างอิง ไม่ต้องแก้โครงเดิม

**Moving average — ตัดทิ้ง**
ต้องมี "ต้นทุนเฉลี่ยปัจจุบัน" ต่อ item ซึ่งเป็นสถานะที่เขียนทับได้
ขัดกับเจตนารมณ์ของ INVARIANT ข้อ 3 และทำให้ต้นทุนย้อนหลังเปลี่ยนได้เงียบ ๆ

## อัตราค่าแรงและ overhead

ไม่ใช้ค่าเดียวบน `work_centers` แต่ใช้ตาราง `work_center_rates` ที่มี
`effective_from` / `effective_to` และมี EXCLUDE constraint กันช่วงเวลาทับกัน

ตอนออกใบสั่งผลิต อัตรา ณ วันนั้นถูก snapshot ลง `work_order_operations`
การแก้อัตราวันนี้จึงไม่กระทบต้นทุนของใบที่ปิดไปแล้ว

## ต้นทุนตามแผน

มาจาก snapshot ในใบสั่งผลิตเท่านั้น:
`work_order_materials.qty_required × standard_unit_cost` (ราคา ณ วันออกใบ)
บวก `work_order_operations` × อัตราที่ snapshot ไว้

ห้ามคำนวณใหม่จาก BOM ปัจจุบัน — นั่นละเมิด INVARIANT ข้อ 2 และทำให้
variance เปลี่ยนไปเรื่อย ๆ ทุกครั้งที่มีคนแก้ BOM

## ฐานปันส่วน overhead

ใช้ **ชั่วโมงเครื่องจริงต่อ work center** (`actual_minutes × overhead_rate_per_hour`)
เลือกเพราะข้อมูลนี้มีอยู่แล้วจากการบันทึกผลหน้างาน ไม่ต้องเก็บอะไรเพิ่ม
ถ้าจะเปลี่ยนไปปันตามมูลค่าวัตถุดิบหรือชั่วโมงคน ต้องเขียน ADR ใหม่

## เงื่อนไขที่ต้องกลับมาทบทวน

ถ้าราคาวัตถุดิบขยับเกิน ±10% ภายในไตรมาสเดียวจนส่วนต่างราคาบิดเบือน
การเทียบแผนกับจริง ให้ทบทวนไปใช้ FIFO
