# 0002 — ล้างระบบ RB เดิมแล้วเริ่มใหม่

- สถานะ: ตกลงใช้
- วันที่: 2026-09-07
- เกี่ยวข้องกับ: เฟส 0

## บริบท

repo นี้เคยเป็น "ระบบใบสั่งงานแผนกขึ้นรูปยาง (RB Shop Floor)" — หน้าเว็บเดียว
(`index.html` ราว 226 KB, vanilla JS ไม่มี build step) คุยกับ Supabase ตรงจาก
เบราว์เซอร์ พร้อมชุด SQL และ ETL ที่ย้ายข้อมูลจากไฟล์ Excel
"ระบบวางแผนการสั่งงานแผนก RB V1.7.1"

ระบบนั้นครอบคลุมเฉพาะแผนก RB ห้าหน่วยงาน (ชั่งเคมี, ตียาง, ฉีดยาง, อบตู้อบ,
อบ HCM) และผูกกับรูปแบบใบสั่งงานกระดาษเดิมโดยตรง

## ทางเลือกที่พิจารณา

**ล้างทิ้งแล้วเริ่มจากโครงใหม่ (เลือก)**
ขอบเขตใหม่กว้างกว่าเดิมมาก — ครอบใบสั่งขาย, BOM หลายระดับ, ธุรกรรมสต็อก,
ต้นทุนจริง — และ INVARIANT ที่วางไว้หลายข้อขัดกับโครงเดิมโดยตรง
โดยเฉพาะข้อ 2 (snapshot BOM), ข้อ 3 (ยอดคำนวณจากธุรกรรม) และข้อ 10
(transaction เดียวพร้อมล็อกแถว) ซึ่งสถาปัตยกรรม "หน้าเว็บคุย Supabase ตรง"
รองรับไม่ได้เลย

**ค่อย ๆ ปรับระบบเดิม — ตัดทิ้ง**
ต้องรื้อทั้ง data model และชั้นการเข้าถึงข้อมูลอยู่ดี เหลือของเดิมที่ใช้ต่อได้
เฉพาะความรู้เรื่องฟอร์มกับสูตรยาง ซึ่งเป็นข้อมูล ไม่ใช่โค้ด

**เก็บของเดิมไว้ในโฟลเดอร์ `legacy/` — ตัดทิ้ง**
git history เก็บให้ครบอยู่แล้ว การมีโค้ดเก่าค้างในต้นไม้ไฟล์ทำให้เซสชันใหม่
ของ Claude หยิบรูปแบบเก่ามาใช้ต่อโดยไม่ตั้งใจ

  ใช้เป็นจุดตั้งต้นของการย้ายข้อมูลได้ ดึงกลับมาจาก git history เมื่อถึงเวลา
