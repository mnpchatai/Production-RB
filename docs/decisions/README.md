# บันทึกการตัดสินใจ (ADR)

เมื่อเลือกทางใดทางหนึ่ง ให้เขียนสั้น ๆ ว่าเลือกอะไร เพราะอะไร และตัดทางไหนทิ้ง

เหตุผล: เซสชันใหม่ของ Claude Code ไม่รู้เหตุผลเดิม และมีแนวโน้มจะเสนอให้ย้อนกลับไป
ทางที่คุณตัดทิ้งไปแล้ว ADR คือสิ่งที่กันเรื่องนี้ ไม่ใช่เอกสารพิธีการ

## รูปแบบ

ตั้งชื่อ `NNNN-เรื่องที่ตัดสินใจ.md` เรียงเลขต่อกัน ไม่ต้องยาว ครึ่งหน้าพอ

```markdown
# NNNN — หัวข้อ

- สถานะ: เสนอ / ตกลงใช้ / ถูกแทนที่ด้วย ADR-XXXX
- วันที่: YYYY-MM-DD
- เกี่ยวข้องกับ: เฟส N / INVARIANT ข้อ N

## บริบท
สถานการณ์ที่ทำให้ต้องตัดสินใจ

## ทางเลือกที่พิจารณา
ทางที่เลือกกับทางที่ตัดทิ้ง พร้อมเหตุผลของแต่ละทาง

## ผลที่ตามมา
สิ่งที่ยอมแลก และเงื่อนไขที่ถ้าเกิดขึ้นจะต้องกลับมาทบทวน
```

## ต้องเขียน ADR เมื่อไหร่

- เลือกวิธีตีราคาต้นทุน (FIFO / moving average / standard)
- เลือกฐานปันส่วน overhead
- เปลี่ยนสูตรสะสม `scrap_pct`
- เพิ่ม dependency ใหม่
- ทุกครั้งที่ตัดสินใจแล้วมีทางเลือกอื่นที่ดูสมเหตุสมผลพอ ๆ กัน
