ทำ code review งานใน branch นี้ในฐานะวิศวกรที่ต้องดูแลระบบนี้ไปอีก 3 ปี

เรียงลำดับความสำคัญแบบนี้ อย่าสลับลำดับ:
1. ความถูกต้องของข้อมูล (สต็อก ต้นทุน สถานะ) — ผิดตรงนี้กู้คืนยากที่สุด
2. การละเมิด INVARIANTS ใน CLAUDE.md
3. พฤติกรรมตอนเกิดข้อผิดพลาดหรือยิงพร้อมกัน
4. ความอ่านง่ายและบำรุงรักษา

สำหรับแต่ละประเด็นให้บอก: ไฟล์:บรรทัด, เกิดอะไรขึ้นถ้าปล่อยไว้, และวิธีแก้

ถ้ามีจุดที่ผมน่าจะพลาดเพราะยังไม่เคยเจอในการใช้งานจริง ให้ชี้ด้วย
